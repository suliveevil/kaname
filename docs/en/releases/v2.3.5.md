# Kaname 2.3.5

[English](v2.3.5.md) · [Chinese](../../zh-CN/releases/v2.3.5.md)

Everything shipped since 2.3.4 in one release: Kaname can now be opened from a URL scheme and
from AppleScript, every key in a shortcut wears its own rounded-square keycap, a command name
that is still clipped scrolls once on hover, the unavailable marker no longer takes width from
the name, and the About tab shows one consistent build identifier.

## Highlights

- **External automation, nine presentation actions.** `kaname://panel` and
  `tell application "Kaname" to show panel` both open the shortcut hint panel; eight more
  parameterless actions — toggle panel, show search, toggle surface, close surfaces, show
  settings, show conflicts, show permissions, show about — are reachable from either entry
  point through one `AutomationAction` enum, one `AutomationRouter` and a `Kaname.sdef`
  dictionary. The URL whitelist is closed: unknown hosts, extra path segments, userinfo, ports
  and overlong strings are refused, and query strings are never interpreted. Deliberately not
  exposed: running a menu item, replaying a keystroke, writing a setting, exporting diagnostics,
  resetting usage statistics and quitting the app — a URL scheme has no authentication and no
  reply channel. Both build paths register `kaname://`, `NSAppleScriptEnabled` and the sdef, and
  the GURL handler queues actions that arrive before the app is ready.
- **One keycap per key.** Shortcuts are drawn as a run of separate 20 pt rounded-square
  keycaps with a 3 pt gap and 13 pt bold glyphs, like a sequence of HTML `<kbd>` elements —
  not one badge around the whole chord. This covers the title-bar modifier chips, chord
  breadcrumbs, panel rows, search results, the statistics column, the hotkey recorder and the
  conflicts list. The symbols chord column was widened from 70 pt to 116 pt to fit a five-key
  chord, and the search and statistics columns were widened to match.
- **A clipped name scrolls once on hover.** `MarqueeText` measures the row's proposed width
  and the text's natural width, then moves the glyphs with an offset inside a clip, so the row
  geometry never changes. One linear pass reveals the last character and stops — there is no
  left-right bounce. Moving the pointer away stops the scroll and restores the name instantly;
  re-entering starts a fresh pass. Names that fit never move, and VoiceOver still reads the full
  label.
- **The unavailable marker moved out of the name.** `lock.slash` marks a menu item whose
  `AXEnabled` is false, with "This menu item is unavailable right now" in the context menu, the
  HUD and the accessibility label. It now shares the always-reserved conflict slot beside the
  shortcut instead of trailing the command name inside a fixed-width column; a real conflict
  still takes priority. It is not folded into the leading verdict dot: that dot's amber means
  "the chord is blocked but a click still runs it", the dot can be switched off, and a
  colour-only state would undo the accessibility review that requires a non-colour marker.
- **The About tab carries one build identifier.** It used to show `v2.3.4 (<commit>)` —
  Kaname's source commit — above a System row reading `Version 27.3 (Build 26C5035r)`, the
  macOS build number. macOS localises *Build* as a second "version number", so the two
  parenthesised codes read as two disagreeing commits for one app. The System row is gone;
  About keeps the version, the data folder, the update check, the repository and the licence.
  macOS version details still go into diagnostics exports and crash reports. The version line
  also keeps the `-dirty` suffix that `stamp_commit.sh` writes for a modified tree, so every
  surface names the same build.

## Fixes worth knowing about

- The first marquee implementation wrapped a `fixedSize` label in
  `.frame(maxWidth: .infinity)`, so the frame grew to the label's natural width: the clip did
  nothing and the measured overflow stayed at zero. A short-lived attempt to hand unused chord
  column width back per row started the menu-path column at a different x on every row and was
  reverted; columns, row heights and paging arithmetic are unchanged.
- The idle hint was rewritten independently in both localizations — the English text reads
  "Click a modifier to filter the list · / searches · Esc closes" — so no English document
  carries Chinese prose.
- `KANAME_PREVIEW=settings-about` now renders the About tab directly, so screenshot runs no
  longer depend on clicking the sidebar. The suite is at 950 tests.

## Upgrade notes

- The bundle identifier and the signing identity are unchanged, so an existing Accessibility
  grant survives this upgrade. Quit Kaname before a `brew upgrade --cask kaname`.
- **This DMG is signed with the local `Kaname Local` identity and is not notarized.** Gatekeeper
  will warn on first launch: approve the app in System Settings → Privacy & Security, or clear
  the quarantine attribute with `xattr -dr com.apple.quarantine /Applications/Kaname.app`.
  Homebrew re-applies quarantine on every upgrade.
- **AppleScript callers need an Automation grant for the sending process.** A host that denies
  Apple events to the calling process returns `-10004`; that is a TCC boundary, not a Kaname
  error. The nine URL scheme actions need no grant. Clickable `.command` probes are provided
  for a GUI session to trigger the first authorisation prompt.
- The Homebrew cask resolves to this build once the tap is updated.
