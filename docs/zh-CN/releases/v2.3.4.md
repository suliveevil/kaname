# Kaname 2.3.4

[English](../../en/releases/v2.3.4.md) · [中文](v2.3.4.md)

一次覆盖 2.3.3 之后九天工作的可靠性发布：浮层面板现在会出现在另一个 App 的原生全屏 Space 上，
翻页不再改变窗口高度，快捷键重放与界面归属得到加固，发布构建也在 Xcode 宏沙箱无法启动的
macOS 27.3 上恢复可用。

## 亮点

- **面板在你看着的那个 Space 打开，包括另一个 App 的全屏 Space。** 原生全屏 Space 属于
  拥有它的 App 的窗口集合；`.canJoinAllSpaces` 只授予「每个桌面」的成员资格，所以那个复用
  的面板在 WorkBuddy 或 Safari 全屏时留在了上次显示过的桌面。窗口现在额外声明
  `.canJoinAllApplications`（macOS 13+），并去掉把窗口钉在出生 Space 的 AppKit 桌面型行为
  `.stationary`。`.statusBar` 层级与 accessory 应用策略不变。2026-11-16 的实机测试记录了
  19 个面板会话、222 次重绘，覆盖 WorkBuddy 与 Safari 的原生全屏 Space，零次落在非活动
  Space；同样的操作序列在 2.3.3 构建上三次读到 `onActiveSpace=false`。
- **非活动 Space 的重挂与一次性自愈保留，并标注为未验证。** 那次测试里修正后的成员声明
  解决了所有读数，两段兜底分支一次都没走到。它们作为未来 WindowServer 行为变化时的防御
  路径保留，测试结论写进源码注释与更新日志。
- **翻到多一张分区卡片的页面不再改变面板高度。** 行数和标题原本就按整个会话最宽的列表
  计算；卡片内边距、卡片标题下的细线和卡片间距却仍按当前页的分组数计算。只放当前 App
  卡片的第一页比带着系统热键的下一页矮 20pt，日志里表现为 `1368x702` / `1368x720`
  交替。`PanelState.cardBudget` 现在把 `PanelSections.cardAndHeadingBudget()` 算出的第三个
  计数经 `EngineState.rowBudgetCache` 送进 `OverlayMetrics`，标题细线也改为跟随会话级标题
  预算。新增 3 条尺寸稳定性测试，用例总数到 936。
- **快捷键重放与界面归属。** 搜索重放只在实际发出 chord 之后记录用量；App 启动与退出通知
  刷新搜索范围和冲突扫描使用的应用列表；系统热键重载与配置文件扫描会重建已打开的面板或
  搜索面板，而不是留着上一批结果。重叠的吞键按下被独立追踪，一次松键不会把另一次按键的
  重复或松开暴露给已关闭界面背后的 App。面板与搜索的运行在异步解析辅助功能之前先捕获
  目标 App，chord 重放在激活目标或投递事件之前预检每一步，包括同一个键的替代拼写。重放
  完成、搜索激活交接与光标恢复都由各自的界面会话持有；替换界面或停止引擎会让旧工作失效，
  而不是注入到后来的 App 里。
- **失焦关闭现在会说明原因。** 关闭面板的前台变化会记下面板年龄、Space 切换年龄与两个
  pid。2026-11-16 的时间线显示，面板打开 1.3 秒后的 Finder 是用户真实切走，因此关闭契约
  保持原样：离开 App 就关闭面板。Space 切换动画里的触发仍然立刻显示面板——压住不显示
  会吞掉按键却什么也看不到——并在 0.75 秒稳定期结束时获得一次重排。
- **发布与备份自动化。** Release CI 把失败的 Release 构建传过日志管道；发布脚本拒绝不指向
  当前提交的同名 tag，重试时从上一个发布生成说明。本地签名的 DMG 不再依赖时间戳网络，
  备份 dry run 在保留额度还有余量时不再预测一次删除。2.3.3 的源码构建号定为 233，与
  2.3.2 的 232 区分；SwiftPM 测试宿主使用显式 `nonisolated` 隔离，以兼容 CI 的 Swift 6.1
  工具链。
- **在 macOS 27.3 上构建。** 这个系统上 `sandbox-exec` 返回
  `sandbox_apply: Operation not permitted`，Swift 的宏插件服务器因此起不来，`@Observable`
  展开报 "produced malformed response"——宏库本身完整无损。`build_release.sh` 现在检测这个
  条件并向 `xcodebuild` 传入 `-disable-sandbox`；Xcode 构建仍然失败时回退到
  `scripts/build_swiftc.sh Release`，与 `install.sh` 一直在用的回退一致。本次发布的 DMG
  由 Xcode 路径构建，是 universal 二进制。
- **仓库资产。** `assets/` 下有产品渲染图、数据流图、交互图与泳道 SVG。2026-11-18 按
  `ba3cd43` 复核了三张流程图，补入全屏 Space 成员声明修复、会话级卡片预算与失焦关闭归因；
  `docs/images/` 的八张界面截图也从已安装的 2.3.4 构建重新采集。

## 升级说明

- 设置、按 App 的统计、日志与本地备份原样沿用。bundle identifier 与签名身份未变，辅助功能
  授权在更新后保留。
- 离开 App 或切换 Space 时面板仍会关闭；到新的前台 App 再唤出一次。
- 全屏覆盖是在单台显示器上的 WorkBuddy 与 Safari 上实测的。多显示器，以及使用
  `CGShieldingWindowLevel` 的 App，处在这次测试范围之外。
- 非活动 Space 重挂与自愈分支没有运行时证据；经过验证的修复是集合行为声明。

## 安装

```
brew tap suliveevil/tap
brew install --cask kaname
```

已经装过：

```
brew upgrade --cask kaname
```

tap 的 cask 已于 2026-11-18 更新到 2.3.4（`suliveevil/homebrew-tap@1eddadd`），新装会直接解析到这个构建。

这个构建已签名但未经公证，所以 macOS 会在首次启动时以"未验证的开发者"拦下它。打开
**系统设置 → 隐私与安全性**，点 **仍要打开**；或执行
`xattr -dr com.apple.quarantine /Applications/Kaname.app`。被要求时授予 **辅助功能**；
只有在面板不出现时才需要加 **输入监控**。
