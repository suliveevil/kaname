# Kaname 2.3.5

[English](../../en/releases/v2.3.5.md) · [中文](v2.3.5.md)

2.3.4 之后的全部改动一次性发布：Kaname 现在可以通过 URL scheme 和 AppleScript 打开面板，快捷键改为「一键一个圆角方形键帽」，仍然放不下的菜单项名称在悬停时单向滚动一次，不可用标记不再挤占名称宽度，「关于」页只保留一处一致的构建标识。

## 亮点

- **外部自动化，九个展示动作。** `kaname://panel` 与 `tell application "Kaname" to show panel` 都能打开快捷键提示面板；另外八个无参数动作——切换面板、显示搜索、切换显示面、收起显示面、显示设置、显示冲突、显示权限、显示关于——通过同一个 `AutomationAction` 枚举、`AutomationRouter` 与 `Kaname.sdef` 词典从两种入口到达。URL 白名单是封闭的：未知 host、多余路径段、userinfo、端口、超长字符串一律拒绝，query 永不解析。刻意不暴露的动作：执行菜单项、回放按键、写设置、导出诊断、重置统计、退出 App——URL scheme 没有鉴权，也没有返回通道。两条构建路径都会注册 `kaname://`、`NSAppleScriptEnabled` 与 sdef，冷启动到达的动作会排队等 App 就绪。
- **一键一个键帽。** 快捷键画成一串独立的 20pt 圆角方形键帽，间隙 3pt、字重 13pt bold，类似一串 HTML `<kbd>`，而不是把整串和弦包成一个徽标。标题栏修饰键 chips、和弦面包屑、面板行、搜索结果、统计列、快捷键录制器与冲突列表全部统一。符号风格的快捷键列由 70pt 放宽到 116pt 以容纳五键和弦，搜索列与统计列同步放宽。
- **仍被截断的名称悬停滚动一次。** `MarqueeText` 量出该行提出的宽度与文字自然宽度，在裁切容器内用 offset 移动字形，行布局因此完全不变。一次线性滚动露出最后一个字符后停住，不再左右弹跳；光标移开立即停止并瞬时复位，再次移入从头开始。放得下的名称不会动，VoiceOver 仍读完整标签。
- **不可用标记移出名称列。** `lock.slash` 表示 `AXEnabled == false`，右键菜单、HUD 与无障碍标签都会说明「这个菜单项当前不可用」。它现在与始终预留的冲突徽标共用快捷键旁的槽位，不再挂在固定宽度标题列内的名称后面；真有冲突时仍以 ⚠︎ 优先。它刻意不并入前置判定灯：黄灯表示「快捷键被挡但点击仍可执行」，灯可以在设置里关闭，而且纯颜色状态会推翻无障碍评审要求的「禁用行必须有非颜色标记」。
- **「关于」页只保留一处构建标识。** 原先页面上方是 `v2.3.4 (<commit>)`（Kaname 源码 commit），下面「系统」行显示 `版本 27.3 (版本号 26C5035r)`（macOS 内部版本号）。macOS 把 Build 本地化成「版本号」，两处括号里的短码因此被读成同一个 App 的两个不一致 commit。系统行已删除；关于页保留版本、数据目录、检查更新、仓库与协议。macOS 版本信息仍写入诊断导出与崩溃报告。版本行现在也保留 `stamp_commit.sh` 为脏工作树写下的 `-dirty` 后缀，所有界面显示同一个构建。

## 值得注意的修复

- 初版跑马灯用 `.frame(maxWidth: .infinity)` 包住 `fixedSize` 文本，容器被撑成文字自然宽度，裁切与溢出测量同时失效。一度尝试「按每行把未用的快捷键列宽还给标题」，结果菜单路径列每行起点不同，已整体撤回；各列宽度、行高与分页算术均未改变。
- 提示面板 idle hint 的中英文分别独立改写，英文为 "Click a modifier to filter the list · / searches · Esc closes"，英文文档不再夹中文文案。
- 新增 `KANAME_PREVIEW=settings-about`，截图可直接渲染「关于」页，不必再点侧栏。测试总数为 950。

## 升级说明

- bundle identifier 与签名身份未变，已有的辅助功能授权在升级后保留。执行 `brew upgrade --cask kaname` 前请先退出 Kaname。
- **本 DMG 使用本机 `Kaname Local` 身份签名，未公证。** 首次启动 Gatekeeper 会警告：在系统设置 → 隐私与安全性里点「仍要打开」，或执行 `xattr -dr com.apple.quarantine /Applications/Kaname.app` 去掉隔离属性。Homebrew 每次升级都会重新加上隔离属性。
- **发送 AppleScript 的进程需要 Automation 授权。** 系统若拒绝该进程发送 Apple event 会返回 `-10004`，这是 TCC 边界，不是 Kaname 的故障；九个 URL scheme 动作不需要授权。随包提供可双击的 `.command` 探针，供 GUI 会话触发首次授权弹窗。
- tap 更新后，Homebrew cask 会解析到这个构建。
